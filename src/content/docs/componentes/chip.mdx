## Cuándo usarlo

- Para acciones secundarias de la cabecera que cambian una preferencia: tema, idioma.
- Para una condición sí/no que filtra una lista («Solo con saldo», «Solo mis órdenes»), como
  interruptor con `aria-pressed`.
- Para filtrar por un campo con varios valores (sucursal, estado), usa la
  [barra de filtros](/componentes/barra-filtros/).
- Para contar registros por estado, usa el [resumen de estatus](/componentes/resumen-estatus/).
- Para la acción principal de una vista, usa un [botón](/componentes/boton/) primario.

## Anatomía

<Example noCode center>
	<button class="chip" type="button"><Icon name="visibility" />Tema</button>
</Example>

1. **Contenedor** — alto mínimo 34px, ancho mínimo 40px, borde `--border`, radio `--r-ctrl`.
2. **Ícono** (opcional) — a la izquierda; hereda el color del texto.
3. **Texto** — `--fs-dense`, peso 600, en `--text-2`.

## Variantes

| Variante | Clase | Úsala para |
|---|---|---|
| Acción | `.chip` | Abrir una preferencia o cambiarla en un paso. |
| Interruptor | `.chip[aria-pressed]` | Activar o desactivar una condición sí/no. |

<Example title="Interruptor">
	<div class="fila">
		<button class="chip" type="button" aria-pressed="true">Solo con saldo</button>
		<button class="chip" type="button" aria-pressed="false">Solo mis órdenes</button>
	</div>
</Example>

## Estados

| Estado | Comportamiento |
|---|---|
| Sobrevuelo | Fondo `--surface-hover`, texto `--text`, borde `--border-2`. |
| Pulsado | Borde `--accent` y fondo `--accent-soft`. Solo en la variante interruptor. |
| Foco | Anillo `--focus-w` en `--accent`, separado `--focus-offset`. |

## Accesibilidad

- Usa `<button type="button">`. El interruptor declara `aria-pressed="true"` o `"false"`; el
  lector anuncia «activado» o «desactivado».
- Un chip sin texto visible (o con una abreviatura, como «ES») lleva `aria-label` completo:
  «Idioma: español».
- El ícono decorativo lleva `aria-hidden="true"`.
- En [modo táctil](/layout/objetivos-tactiles/) el alto sube al mínimo táctil del sistema.
