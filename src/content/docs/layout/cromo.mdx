## Anatomía

1. **Barra lateral** (`.side`) — fondo `--chrome`, ancho fijo, `flex-shrink: 0`.
2. **Marca** (`.side .marca`) — isotipo y wordmark «D.P. Energy». Ver [Logotipo](/fundamentos/logotipo/).
3. **Rótulo de grupo** (`.grp`) — 10,5px con espaciado de letra: la única excepción al suelo de
   12px. Ver [Tipografía](/fundamentos/tipografia/).
4. **Ítem** (`.it`) — ícono y texto, 38px de alto mínimo.
5. **Contador** (`.cuenta`) — avisos pendientes de esa sección.
6. **Zona principal** (`.main`) — `flex: 1` y `min-width: 0`, para que una tabla ancha haga scroll
   dentro y no empuje la página.
7. **Barra superior** (`.barra-sup`) — título de la pantalla y acciones globales.

```css
.app  { display: flex; min-height: 100vh; }
.side { width: 220px; flex-shrink: 0; background: var(--chrome); color: var(--chrome-ink); }
.main { flex: 1; display: flex; flex-direction: column; min-width: 0; }
```

## Estados del ítem

| Estado | Comportamiento |
|---|---|
| Reposo | Texto `--chrome-dim` |
| Sobrevuelo | Fondo `--chrome-hover`, texto `--chrome-ink` |
| Actual | `aria-current="page"`: fondo `--chrome-activo`, texto `--chrome-ink` en 600 y filete izquierdo de 3px en `--ok` |
| Foco | Anillo en `--chrome-focus` |

El ítem actual se marca con `aria-current="page"`, no con una clase: el mismo atributo da el estilo
y lo anuncia al lector de pantalla.

## Paleta del cromo

El cromo es oscuro en los dos temas y tiene tokens propios, para que un cambio en las superficies
del contenido no lo arrastre.

- `--chrome` es solo estructura. Nunca es fondo de página ni de una tarjeta.
- **Foco:** dentro de `.side` el anillo usa `--chrome-focus`. `--accent` no llega a 3:1 sobre el
  azul del cromo.
- **Contador:** usa `--chrome-alerta` con `--chrome-alerta-ink`. El rojo de estado (`--err`) está
  pensado para caer sobre una superficie clara; sobre el cromo en tema oscuro se funde. Un aviso
  sobre `--surface` sigue usando el [semáforo](/fundamentos/color/#semáforo).

## Anchos

| Ancho de pantalla | Barra lateral |
|---|---|
| 1100px o más | Completa: ícono y texto |
| De 860 a 1100px | Colapsada: solo íconos |
| Menos de 860px | Cajón que se abre sobre un velo |

En modo colapsado el texto del ítem pasa a etiqueta emergente y a `aria-label`; no desaparece. El
contador se mantiene sobre el ícono.

## Accesibilidad

- La barra lateral es un `<nav>` con `aria-label`. Si hay más de una navegación, cada una con un
  nombre distinto.
- El contador lleva texto para el lector de pantalla: «3 pendientes», no solo «3».
- Los botones-icono de la barra superior nombran lo que hacen: «Avisos, 3 sin leer».
- Los íconos de los ítems son decorativos (`aria-hidden="true"`); el nombre es el texto.
