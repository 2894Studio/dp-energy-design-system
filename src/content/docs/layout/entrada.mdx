## Estructura

1. **Columna de marca** (`.brand`) — fondo `--marca-lienzo`, texto `--marca-lienzo-ink`, wordmark en
   su variante para fondo oscuro y, si la hay, la ilustración de la escena. No lleva controles.
2. **Columna de acceso** (`.access`) — superficie clara, título, una frase de ayuda y la acción de
   entrada.

Las dos columnas van lado a lado desde 920px; por debajo se apilan y la columna de marca baja a un
alto fijo, para que la acción de entrada quede a la vista sin desplazarse.

```css
.split  { display: flex; flex: 1; min-height: 0; }
.brand  { flex: 1.05; min-height: 520px; padding: var(--sp-6) var(--sp-8);
          background: var(--marca-lienzo); color: var(--marca-lienzo-ink); }
.access { flex: 1; padding: var(--sp-6) var(--sp-8); }

@media (max-width: 920px) {
  .split { flex-direction: column; }
  .brand { flex: none; min-height: 300px; }
}
```

## Columna de acceso

- **Una sola acción primaria:** el [botón de acceso](/componentes/boton-acceso/) (`.gbtn`), de 48px
  de alto. El resto de botones de la pantalla sube a 44px: son las dos o tres acciones de toda la
  pantalla.
- El botón de acceso se bloquea en el manejador de JS mientras comprueba, no solo con CSS:
  `pointer-events: none` detiene el ratón, no el teclado.
- El título de la tarjeta va a 21px, fuera de la escala: es el único título de la pantalla.
- **Un solo contenedor para todos los estados.** Acceso, comprobando, sin permiso y error viven
  dentro de la misma tarjeta; la pantalla no cambia de forma según lo que tenga que decir. Ver
  [Vistas de estado](/patrones/vistas-de-estado/).
- Si el acceso flota sobre la escena de marca, la tarjeta usa la
  [superficie translúcida](/fundamentos/elevacion/) `.glass`, con su respaldo opaco.

## Accesibilidad

- La columna de acceso es el `<main>` de la pantalla; la de marca es decorativa y su ilustración
  lleva `aria-hidden="true"` o `alt=""`.
- El título es el `<h1>` de la pantalla.
- Mientras comprueba, el botón lleva `aria-busy="true"` y el cambio de estado se anuncia en una
  región `role="status"`.
- Una ilustración animada en la columna de marca se pausa pulsándola. Ver
  [Movimiento](/fundamentos/movimiento/).
