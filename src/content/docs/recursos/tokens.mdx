## Fuente única

- **Los tokens viven en `src/tokens/tokens.json`**, en formato [DTCG](https://www.designtokens.org/)
  (`$type`, `$value`, `$description`).
- **El valor oscuro** va en `$extensions."com.dpenergy.theme".dark`. Un token sin valor oscuro vale lo
  mismo en los dos temas.
- **El CSS se genera** desde ese archivo con `scripts/build-tokens.mjs`. No edites el CSS a mano: el
  siguiente build lo sobrescribe.

```json
"accent": {
  "$type": "color",
  "$value": "#3E7A4C",
  "$extensions": {
    "com.dpenergy.theme": { "light": "#3E7A4C", "dark": "#4A8F5A" }
  },
  "$description": "Acción principal. Nunca igual a --ok."
}
```

## Cómo consumirlos

1. Enlaza el CSS antes que cualquier otra hoja de estilos. Lo tienes en [Descargas](/recursos/descargas/).

   ```html
   <link rel="stylesheet" href="/css/dp-energy-tokens.css" />
   ```

2. Usa siempre `var(--token)`.

   ```css
   .mi-componente {
     background: var(--surface);
     border-radius: var(--r-card);
     padding: var(--sp-4);
   }
   ```

3. El tema claro está en `:root`. El oscuro se activa con `data-theme="dark"` en `<html>` o, sin
   atributo, según `prefers-color-scheme`.

**Nunca escribas un hexadecimal literal en un componente.** Si algo no tiene token, añádelo a
`tokens.json` siguiendo el patrón de nombres:

| Familia | Patrón | Ejemplo |
|---|---|---|
| Estado | `--{estado}`, `--{estado}-bg`, `--{estado}-ink` | `--warn`, `--warn-bg`, `--warn-ink` |
| Superficie y texto | `--surface`, `--surface-2`, `--text`, `--text-2`… | `--text-3` |
| Cromo | `--chrome-{parte}` | `--chrome-hover` |
| Serie de gráfica | `--serie-{n}` | `--serie-2` |
| Espaciado | `--sp-{n}` (múltiplos de 4px) | `--sp-4` |
| Radio | `--r-{uso}` | `--r-card` |
| Tipografía | `--fs-{uso}`, `--lh-{uso}`, `--font-{uso}` | `--fs-meta` |
| Sombra | `--sh-{nivel}` | `--sh-float` |
| Movimiento | `--dur-{uso}`, `--ease-{curva}` | `--dur-base` |
