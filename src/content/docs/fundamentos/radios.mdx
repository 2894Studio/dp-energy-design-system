## Cuándo usar cada uno

| Token | Valor | Úsalo para |
|---|---|---|
| `--r-ctrl` | 6px | Botones, campos, buscador, chips, etiquetas de estado, opciones de un menú |
| `--r-card` | 10px | Tarjetas, contenedor de tabla, menús y popovers |
| `--r-modal` | 16px | Diálogos, tarjeta flotante de la pantalla de entrada, vistas de estado |
| `--r-pill` | 999px | Resumen de estatus, filtros de la barra de filtros, contadores |

- **El radio crece con el objeto.** Un control dentro de una tarjeta conserva `--r-ctrl`; no
  hereda el radio de su contenedor.
- **`--r-pill` marca una pieza de filtro o un contador.** Un botón con forma de píldora se lee como
  un filtro; un botón usa `--r-ctrl`.
- **Lo circular usa `50%`,** no un token: el botón de información, el botón flotante, el medallón
  de una vista de estado. Su radio depende del tamaño, no del tipo de objeto.
