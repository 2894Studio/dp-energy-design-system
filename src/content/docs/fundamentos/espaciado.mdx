Escala de base 4px. El número del token es un identificador, no un multiplicador: `--sp-5` vale
20px y `--sp-12` vale 48px. No hay fórmula; consulta la tabla.

## Escala

		<div><code>{'--sp-6'}</code><span>24px</span><i style="width:var(--sp-6)"></i></div>
		<div><code>{'--sp-8'}</code><span>32px</span><i style="width:var(--sp-8)"></i></div>
		<div><code>{'--sp-12'}</code><span>48px</span><i style="width:var(--sp-12)"></i></div>
	</div>

| Token | Valor | Uso |
|---|---|---|
| `--sp-1` | 4px | Separación mínima entre elementos muy pegados |
| `--sp-2` | 8px | Ícono y texto, hueco entre chips |
| `--sp-3` | 12px | Hueco interno de una fila, celda de tabla |
| `--sp-4` | 16px | Relleno de control, hueco entre bloques cortos |
| `--sp-5` | 20px | Relleno interior de un diálogo |
| `--sp-6` | 24px | Relleno de sección, margen entre grupos |
| `--sp-8` | 32px | Relleno de tarjeta principal, columnas del layout |
| `--sp-12` | 48px | Separación grande entre secciones |

**Un token que no existe falla en silencio.** Un `var()` que no resuelve invalida la declaración
entera: un `padding: var(--sp-7)` computa a 0, sin error en consola, y el contenido queda pegado
al borde. Si un espaciado se ve raro, comprueba primero que su token esté definido.

## Alturas de fila

Una tabla densa tiene dos alturas de fila.

| Densidad | Alto | Úsala para |
|---|---|---|
| Cómoda | 40px | Por defecto |
| Compacta | 32px | Solo si la pantalla ofrece densidad, y entonces con menos contenido por fila |

La densidad compacta reduce contenido, no solo espacio: la segunda línea de la celda pasa a
etiqueta emergente. Detalle en [Tabla](/componentes/tabla/).

## El relleno de un contenedor vive en el contenedor

Un bloque hecho de filas opcionales (título, búsqueda, filtros) declara su relleno inferior en el
propio bloque. Nunca lo delega en la fila que hoy va última: el día que esa fila no está, el
bloque se queda sin cierre.

<Guidelines>
	<Guideline type="do" caption="El relleno inferior es de la cabecera: con solo el título, cierra igual.">
		<div class="esp-cab bien">
			<header><h4>Órdenes de instalación</h4></header>
			<div class="cuerpo">Contenido de la pantalla</div>
		</div>
	</Guideline>
	<Guideline type="dont" caption="El relleno lo ponía la fila de chips; sin ella, el título queda pegado a la línea.">
		<div class="esp-cab mal">
			<header><h4>Órdenes de instalación</h4></header>
			<div class="cuerpo">Contenido de la pantalla</div>
		</div>
	</Guideline>
</Guidelines>

- Cada fila declara solo su relleno superior. El inferior es del contenedor.
- Así el bloque cierra igual con título y chips, con título y filtros, o con el título solo.
- **Cómo se detecta:** una cabecera con solo título debe dejar 12px (`--sp-3`) entre su control
  más bajo y la línea divisoria. Si ese control queda a 0px de la línea, el relleno estaba en un
  hijo.

### `:last-child` no distingue lo oculto

No lo resuelvas con `:last-child`. Un elemento con `hidden` no ocupa espacio, pero sigue siendo
el último hijo: se lleva el relleno y la fila visible se queda sin cierre. Basta con que la
cabecera gane una fila condicional (las pastillas de filtros aplicados, que nacen ocultas) para
que la regla se rompa sola.

```css
/* Mal: si la última fila está oculta, se lleva el relleno */
.cabecera > :last-child { padding-bottom: var(--sp-3); }

/* Bien: el relleno es del contenedor; cada fila declara solo el superior */
.cabecera { padding-bottom: var(--sp-3); }
.cabecera > * { padding-top: var(--sp-3); }
```

La regla vale para cualquier bloque compuesto por filas opcionales: si al quitar una fila el
bloque se descuadra, el relleno estaba en el sitio equivocado.
